## 关于我

我目前是[西安电子科技大学](https://www.xidian.edu.cn/)硕士研究生，本科毕业于[长沙理工大学](https://www.csust.edu.cn/)。

我的研究方向主要包括端到端自动驾驶、机器人学与计算机视觉。我深信，一切智能行为都始于感知——没有对世界的准确"看见"，便无从谈起对世界的从容"应对"。感知，是机器人理解世界、接触世界的原点。因此，我的研究始终围绕如何让机器在复杂、动态、不确定的环境中建立稳健而高效的视觉认知能力。

**研究兴趣**

- 端到端自动驾驶
- 机器人学
- 计算机视觉
